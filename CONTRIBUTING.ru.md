# Внесение правок

**Лицензия:** [CC BY-SA 4.0](SPEC/LICENSE) · [English](CONTRIBUTING.md)

## Источник истины

`SPEC/FORMAT.md` определяет чеклист; `SPEC/RETIREMENT.md` — уборку.
Навыки, команды и скрипты следуют этим контрактам. Расхождение — ошибка
инструмента, а не повод незаметно ослабить контракт. Концепты объясняют решения.

## Языки и лицензии

Инструкции агенту, комментарии и docstring кода, нормативные контракты английские.
Руководства для человека имеют английскую основу и русский перевод. Чеклист
и общение агента следуют языку пользователя; цитируемое остаётся дословным.
Сообщения инструментов и индексы по умолчанию английские. Псевдонимы EN/RU
и канонические ASCII-поля сохраняются.

`SPEC/`, `docs/` и `CONTRIBUTING*.md` — CC BY-SA 4.0. Остальные пути —
AGPL-3.0-or-later, включая корневые README и инструкции агенту. Стандартные
тексты лицензий сохраняются дословно. Перемещение или перевод не должны молча
менять лицензию файла; таблицы README должны быть согласованы.

## Версии

Версия плагина записана в шести местах:

```text
.claude-plugin/plugin.json
.claude-plugin/marketplace.json
.agents/plugins/marketplace.json
.codex-plugin/plugin.json
README.md
README.ru.md
```

Все совпадают; оба changelog содержат запись релиза. Хосты сравнивают версию
при обновлении: отставший манифест может не доставить изменённое поведение
в установленную копию. SemVer: patch для совместимых исправлений; minor
для новых команд и полей; major для несовместимых изменений с миграцией.

Версия формата независима и меняется только при изменении его контракта.
Зеркала маркетплейса должны совпадать побайтно.

## Порядок изменения

1. Назвать наблюдаемый результат и доказательство изменения.
2. При изменении поведения сначала обновить соответствующий контракт.
3. Добавить регрессию, воспроизводящую дефект или проверяющую новый результат.
4. Реализовать небольшой завершённый шаг; отделять поведение от оформления.
5. Согласовать языковые версии, версии плагина и changelog.
6. Выполнить проверки и прочитать diff до коммита.

```bash
python3 scripts/check-versions.py
python3 scripts/check-skills.py
python3 scripts/check-docs.py
bash tests/selftest.sh
python3 tests/mutate.py
diff .claude-plugin/marketplace.json .agents/plugins/marketplace.json
git diff --check
```

Самотест включает парсер, хуки, срок жизни и уборку. Мутация обязана доказать,
что замена произошла; неизменённый файл означает сломанный стенд, а не успешный
тест. Мутации покрывают известные регрессии и не заменяют враждебные входы
или независимое ревью.

## Рабочие данные

Не коммитить `_kanon/`, `.kanon/`, архивы и журналы, транскрипты, приватные
отчёты ревью, имена клиентов, учётные данные, внутренние адреса и личные
пути файловой системы. Примеры синтетические. До открытия репозитория
проверяются текущее дерево и доступная история: правка HEAD не убирает историю.
Публикация и преобразование истории требуют явного разрешения владельца.

## Правила хуков и файловых операций

Хуки не блокируют работу. Внутренняя ошибка даёт выход 0. PreToolUse напоминает
один раз за сессию; порог сбора сохраняется. Архивирование явное и не закрывает
открытые пункты. Возраст не разрешает удаление. Файловые операции сохраняют
восстанавливаемый материал, отказывают при ссылках и совпадении имён,
а до удаления тары записывают историю решения.

## Маршрутизация

`check-skills.py` проверяет размещение и форму метаданных, а не автоматический
выбор. Записываются вход, версии хоста и плагина и тип вызова: естественный,
ручной или после напоминания хука. K7 — прогон с сопоставимой сессией без
плагина. Доступ к eval конкретного хоста не предполагается.
