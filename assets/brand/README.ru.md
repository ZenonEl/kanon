# Ассеты Kanon

[English](README.md) · **Русский** · [Лицензия: AGPL-3.0-or-later](../../LICENSE)

Выбранный знак — лист приёмки: два открытых пункта и один принятый результат.
Тёмно-синий, бирюзовый и небольшой коралловый акцент связывают его с соседним
инструментом Herald.

## Файлы

- `kanon-logo.png`: знак 1024 × 1024 с прозрачностью. Сохраняйте пропорции и
  отступы; на светлом фоне контраст наиболее отчётливый.
- `kanon-social-preview.png`: выбранное превью репозитория 1200 × 630 с
  непрозрачным фоном. Собранный материал питает критерии приёмки; усиленный
  корень связан с закрытым пунктом, у которого есть доказательство.

Социальную картинку можно загрузить в настройку Social preview репозитория
GitHub. Сохраняйте имя файла, чтобы ссылки в README продолжали работать.
Рабочие исходники, варианты и заметки ревью хранятся локально вне файлов,
попадающих в Git.
