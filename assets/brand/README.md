**English** · [Русский](README.ru.md) · [License: AGPL-3.0-or-later](../../LICENSE)

The selected mark is a checklist sheet: two open items and one accepted result.
Navy, cyan and a small coral accent connect it to the neighboring Herald tool.

## Files

- `kanon-logo.png`: transparent 1024 × 1024 mark. Preserve its proportions and
  padding; place it on a light background for the clearest contrast.
- `kanon-social-preview.png`: opaque 1200 × 630 preview selected for this
  repository. Gathered material feeds acceptance criteria; the stronger root
  connects to the closed, proof-bearing example.

Use the social image for GitHub's repository Social preview setting. Keep the
filename stable so README links remain valid. Working sources, trial versions
and review notes are stored locally outside the tracked release files.
